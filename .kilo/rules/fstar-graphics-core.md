# Kilo Rule: F* Graphics Core - Push After Every Module

## Project truth
- Graphics engine core for Android, core logic ONLY.
- No Android APIs, no NDK calls, no Vulkan, no OpenGL, no file IO inside core.
- Write Low* in F*, KaRaMeL extracts to C11.
- I do NOT use vision. I describe bugs in text, you fix from text.
- Model: Lightning for speed by default. Ultra only if a proof fails twice.
- CI is the source of truth.

## Workflow - one module at a time
1. Research + Plan only, wait for me to say "go"
2. Code one module: src/<Module>.fst, max 300 lines, Low* only
3. Test: tests/c/test_<module>.c
4. PUSH AFTER EVERY MODULE:
   ```
   git status
   git add src/<Module>.fst tests/c/test_<module>.c
   git commit -m "feat(core): <Module> verified F* + KaRaMeL C"
   git push origin HEAD
   ```
5. STOP and wait. Tell me: "Pushed <Module>. Waiting for CI."
6. I paste CI errors, you fix ONLY that module, re-push with fix(core): <Module> <fix>

## Never do
- Never push 2 modules at once.
- Never edit out/ by hand. out/ is generated by KaRaMeL in CI.
- Never add Android / NDK / GPU code to src/.
